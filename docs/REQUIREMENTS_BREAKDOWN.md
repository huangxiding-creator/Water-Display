# 江巷灌区数字孪生平台 — 功能需求分解 (FRB)

> **来源**：`初步设计报告/江巷信息化（第15章）.pdf`（215 页）
> **用途**：把大文件拆成可建造的结构化功能需求库；作为站点生成器的种子数据
> **方法**：按报告自身章节架构分解（与业主阅读心智一致），每项需求带 ID，可追溯、可勾选、可标注优先级
> **状态**：✅ 已完整覆盖 15.1 / 15.4 / 15.5.1 / 15.5.3；⏳ 15.2/15.3/15.5.2 待第三批深读补全（不影响提案）

## ID 规则
`FRB-<章>-<模块>-<序号>`，例如 `FRB-51-MODEL-03` = 15.5.1 模型库第 3 项。

## 优先级图例
- **P0 必做**：核心展示价值，业主最关心
- **P1 应做**：完整性的关键拼图
- **P2 可做**：锦上添花/后续迭代

## 展示要素 vs 交互要素
- **展示**= 看得到（数据/图表/图文/3D）
- **交互**= 点得动（切换/筛选/拖拽/播放预演/批注反馈）

### FRB-51-MODEL-01  水文预报模型  [P0]
- 子类：①水库来水预报（13 座水库：江巷/蔡桥/傅光/墩子王/李园/储城/曹冲/湾孙/大余/扫帚坝/岗王/马桥坝/仓西；方法：逐步回归/多元回归/周期均值叠加/自回归/小波分析自回归；输出 3~7 天日入库 + 旬月预报；GB/T 22482-2008）②渠道来水预报（中长期/短期/实时洪水三时间尺度）③省厅已建模型调用（滁河干流/河道演进/产汇流校正/中长期）④池河关键站实用模型
- 交互：点击水库看预报过程线 mock

### FRB-51-MODEL-02  需水预测模型  [P0]
- 三类需水：①农业灌溉（水稻各生育期：返青/分蘖/分蘖后/孕穗/抽穗开花/乳熟/黄熟 + 上下限；墒情耦合）②城乡（城镇/农村生活，人均日用水量法 + 公共需水）③生态（月/季/汛期/非汛期/年）
- 范围：江巷水库直供片/联合灌片/余庄片/八龙片
- 交互：拖动时间轴看需水过程

### FRB-51-MODEL-03  水动力学模型  [P0]
- 5 个建模部分（直供片/联合灌片/余庄片/八龙片/引江骨干联合调度），分段细化（如直供片 7 段、联合灌片 9 段）
- 内容：①一维恒定流（水位/流量/糙率）②一维非恒定流（流达时间/最优响应时间）③水位-流量-蓄量关系曲线 ④实时响应算法
- 交互：**预演模拟器**——选渠段、调流量，看水位过程线动态演进

### FRB-51-MODEL-04  水资源配置模型  [P0]
- 输入：水文预报 + 需水预测；6 个分区配置（驷马山骨干/直供片/联合灌片/余庄片/八龙片/水源联通）
- 两时间尺度：中长期（月步长年方案，丰/平/枯典型年集合）+ 短期（实时优化）
- 交互：**配置沙盘**——切换丰/平/枯年份，看分区配水饼图/桑基图变化

### FRB-51-MODEL-05  输配水联合调度模型  [P0]
- 5 部分（同水动力）；目标：配水时间最短 + 调度水量最少；示范区郭集片
- 交互：3D 输配水动态仿真嵌入

### FRB-51-MODEL-06  防洪调度模型  [P0]
- 目标：江巷水库 + 下游西/中/东干渠；输出淹没范围/水深/历时；方案对比
- 交互：**淹没预演**——不同频率洪水，看淹没动画 + 风险热力图

### FRB-51-MODEL-07  泵站经济运行模型  [P1]
- 滁河一级站；机组层（性能曲面高效区）+ 泵站层（流量-扬程-最优效率曲面）

### FRB-51-MODEL-08  地面标定/遥感监测  [P1]
- 种植结构调查（5/8 月两期，80 点）、水稻面积调查（4-9 月周 cycle，APP）、塘坝蓄水测量（无人船 0.15-300m）、作物耗水量（FAO-56）

### FRB-51-MODEL-09  工程安全监测模型  [P0]
- 范围：13 中型泵站 + 1 大型（滁河一级站）+ 4 进水闸 + 11 节制闸 + 4 渡槽
- 方法库：多元线性逐步回归/全回归/偏最小二乘
- **三级安全评价**：一级（正常/异常）→二级（正常/轻/中/重度异常）→三级（正常/基本正常/局部/严重异常险情）

### FRB-51-MODEL-10  智能识别模型  [P1]
- 视频智能识别（表盘识数/指示灯/液位）+ 音频识别（振动/温度/声音，边缘算法仓）

### FRB-51-MODEL-11  数字模拟仿真引擎  [P0]
- 数据接入（2D: SHP/TIFF；3D: MAX/FBX；BIM: RVT/DGN/IFC；倾斜: OSGB；服务: WMTS/3DTiles）
- 场景管理/模型轻量化/渲染（本地高渲染+在线云渲染）/仿真（碰撞/物理/特效/空间分析）/场景优化（数百种植被、水体、阴影风摆）
